# sBridge 0.9.0 (preview)

**Status:** preview release. The implementation below passed automated checks and
focused real-game validation with one controller and two games. Broader provider,
controller-feature, and Steam-identity claims remain future work.

## What this release contains

- **Stable game library:** games register with immutable UUIDs; `launch <game-id>`
  shortcuts resolve stored launch details. Existing shortcuts are never rewritten.
- **Registered Games editor:** edit saved launch details, argument tokens, hints,
  and UUID-scoped integration/watch preferences with transactional save/rollback.
- **Providers:** Xbox / Microsoft Store packaged discovery (responsive,
  cancellable), Epic Launcher manifest discovery and protocol activation, and
  custom Win32 registration/launching.
- **Session tracking:** multi-hop launcher/bootstrap/game monitoring with scored
  matching; ambiguous or unidentified sessions are errors, never silent success.
- **Steam account selection:** explicit per-account import targets, safe first-file
  creation, per-account deduplication, and scoped removal. Empty selections block
  writes instead of broadening them.
- **Bounded SteamGridDB artwork:** typed API use, validated PNG/JPEG images,
  queued background jobs owned by the settings UI, independent failure reporting.
- **Owned SISR lifecycle:** retained process handle plus per-user/session lease;
  existing SISR instances are left untouched. Optional managed startup generates
  per-session configuration, waits for a compatible owned API, and verifies the
  effective controller configuration before game activation.
- **Per-game controller profiles:** Xbox 360, DualShock 4, DualSense, DualSense
  Edge, and Switch 2 Pro virtual output types plus gyro/touchpad/back-button
  passthrough, stored per registered UUID.
- **Diagnostics:** read-only summary with a safe copy action, bounded log rotation
  (2 MiB + three archives), and bounded managed-session retention.
- **Distribution:** framework-dependent and self-contained Windows x64 ZIPs with
  payload hashes, plus Windows CI (restore/build/test/packages).

## Validated

- Hosted Windows CI: **358 tests passed, five explicit opt-in cases skipped**,
  warning-as-error build, both package modes checked
  (`docs/validation/2026-10-08-hosted-ci.md`).
- Clean Windows Sandbox run of the earlier development self-contained ZIP with no
  installed .NET runtime (`docs/validation/2026-10-08-clean-machine.md`). This
  gate must be repeated for the exact 0.9.0 ZIPs before calling them verified.
- Real games with a Steam Controller 2 (maintainer-observed):
  - The Witcher 3 remastered, created shortcut, SISR disabled (Steam Input).
  - Hades II with legacy SISR startup.
  - Hades II with managed startup, inherited options, controller connected after
    launch — input worked.
  - Hades II with managed startup and an explicit Xbox 360 override — input,
    normal exit, and Steam returning to Play worked.
  - Details and limits: `docs/validation/2026-10-09-real-games.md`.

## Versioning note

- **Package version:** `0.9.0` (recorded in ZIP names and manifests).
- **Assembly version:** reports `1.0.0.0`; the package label is the release
  identifier for this preview.
- Requires the **x64 .NET 10 Desktop Runtime** for the framework-dependent
  package; the self-contained package bundles it. Keep all extracted files
  together. SISR remains external and optional.

## Unsigned build notice

This preview is **unsigned**. Windows SmartScreen may warn on first launch;
choose “More info → Run anyway” only for binaries you obtained from this
project's release artifacts and verified against the published checksums.

## Not claimed

- Compatibility beyond the reported games, providers, and controller/output type.
- Gyro/touchpad/back-button behavior on real hardware.
- Byte-level Steam readback or AppID/quoting fixtures (no identity-policy change
  is included).
- Epic authentication/commercial EAC chains beyond the tested behavior.
- Steam binding/layout selection (configured in Steam, not by these profiles).
- Signed binaries, automatic updates, or background services.
