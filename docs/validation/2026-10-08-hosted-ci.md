## Initial run and correction

The [first run](https://github.com/jxsparrou/controller-bridge/actions/runs/37845096934)
passed restore/build but reported two native test-fixture cleanup failures: Windows
denied deletion of staged `Game.exe` immediately after forced process termination.
The failures were in teardown, not the reported session assertions. The fixture
now retries deletion of only its owned directory for at most five monotonic
seconds, accommodating executable-image/scanner-handle release. All assertions
and path/creation-time scoped process cleanup remain intact. Local focused checks
and the full hosted rerun passed.

The runner reported an upload-action Node 20 deprecation notice while forcing that
pinned action onto Node 24. Uploads succeeded; this is separate from compiler
warnings and can be addressed in routine action-version maintenance.

## Scope

CI verifies default portable/native controlled Windows tests and non-desktop
package launches. It does not run opt-in installed SISR/Appx/UI checks, live Steam
editing/readback, protected commercial games or physical controllers. Clean-machine
proof for the recorded local development ZIP is documented separately in
[the Sandbox validation record](2026-10-08-clean-machine.md); repeat that gate for
new release ZIPs.
